Use JSON keyed by the stable page IDs from the manifest. Each page has an entry per selected language. Each language entry has these six nonempty string fields.

| Field | Purpose |
|---|---|
| title | A short title for the page and the directory |
| idea | Two or three brief sentences for quick reading in class |
| body | An explanation that adds conditions, steps, diagram interpretation or a worked example |
| key | One concise insight worth collecting in a cheat sheet |
| question | A question the student can attempt independently, ideally using a different input or checking a boundary |
| answer | The answer and enough reasoning to verify it |

Keep symbols, units, assumptions and original values. Identify invented examples as supplementary examples and cite other material by document and original page number. Use “待核对原页” or “Verify on the source page” for details that cannot be confirmed. Use Markdown for lists, tables and emphasis in the explanation and answer. Inline LaTeX uses `\(...\)`; displayed LaTeX uses `\[...\]` or `$$...$$`. For cover, divider and administrative pages, keep the text proportionate and use a specific orientation or logistics question grounded in the page.

Check meaning as well as spelling. The idea answers what the page is about. The explanation helps a learner work with it. The question tests a new step and the answer resolves it. The builder rejects missing fields and normalized verbatim duplicates in the same language. Review representative pages for paraphrased duplicates and factual accuracy before delivery. For dual-language output, verify both versions cover the same material and calculations.


For each representative page, verify the following before delivery:

- Read the Idea on its own. A learner should quickly understand what the page teaches and when it applies.
- Compare the Explanation with the Idea and original page. Identify at least one useful addition, such as a derivation step, an assumption, a boundary condition, or a figure interpretation. Rewrite paraphrases that add nothing.
- Try the self-check without looking at the answer. Where appropriate, use a different input or a boundary case so the learner must apply the idea. Solve it independently and check that the answer explains the reasoning. For cover or logistics pages, use a concrete source-based orientation question.
